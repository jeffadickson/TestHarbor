T:TestHarbor.ResourceCoordinator

summary: Coordinates atomic sets of named resources within one process.

remarks: Requests are FIFO. The oldest blocked request can delay unrelated requests. Leases are not reentrant; declare every needed resource in one request.

M:TestHarbor.ResourceCoordinator.GetSnapshot

summary: Returns detached resource state, including current owner labels and wait counts.

M:TestHarbor.ResourceCoordinator.GetEvents

summary: Returns the latest 256 events in chronological order.

M:TestHarbor.ResourceCoordinator.ResetQuarantine(System.String,System.String)

summary: Clears a quarantine after caller-controlled recovery and after all owners leave.

param name: Resource recovered by the caller.

param recoveryReason: Nonempty audit explanation; this method does not recover physical hardware.

P:TestHarbor.ResourceCoordinator.Shared

summary: Gets the coordinator shared by default across TestHarbor sessions in this process.

M:TestHarbor.ResourceCoordinator.AcquireAsync(System.Collections.Generic.IEnumerable{TestHarbor.ResourceRequest},System.Threading.CancellationToken,System.String)

summary: Waits for and atomically acquires all requested resources.

param requests: Requirements; duplicates merge to the strongest access mode.

param cancellationToken: Cancels waiting, but does not revoke a granted lease.

param owner: Optional diagnostic label; a unique label is generated when omitted.

returns: An idempotently disposable lease; retain it until cleanup is complete.

T:TestHarbor.ResourceLease

summary: An acquired resource set; quarantine before release if cleanup cannot establish safe reuse.

M:TestHarbor.ResourceLease.Quarantine(System.String)

summary: Blocks future owners without revoking existing owners, while retaining this lease.

param reason: Explanation of why explicit recovery is required.

M:TestHarbor.ResourceLease.Dispose

summary: Releases ownership once; an existing quarantine remains in effect.

T:TestHarbor.TestSession

summary: Owns one test's dependency scope and resource lease.

remarks: Dispose only after test work has joined. Cleanup is awaited before resources are released.

P:TestHarbor.TestSession.Services

summary: Gets the services scoped to this test session.

M:TestHarbor.TestSession.OpenAsync(System.Collections.Generic.IEnumerable{TestHarbor.ResourceRequest},System.Action{Microsoft.Extensions.DependencyInjection.IServiceCollection},TestHarbor.ResourceCoordinator,System.Threading.CancellationToken,TestHarbor.TestSessionOptions)

summary: Acquires resources, then creates a validated dependency scope.

param resources: All resources needed by setup, test, and cleanup.

param configure: Registers services without accessing physical resources.

param coordinator: Optional coordinator; defaults to the process-wide instance.

param cancellationToken: Cancels resource acquisition.

param options: Cleanup failure policy and diagnostic identity.

returns: A session to dispose asynchronously.

M:TestHarbor.TestSession.RunAsync(System.Collections.Generic.IEnumerable{TestHarbor.ResourceRequest},System.Func{TestHarbor.TestSession,System.Threading.CancellationToken,System.Threading.Tasks.Task},System.Action{Microsoft.Extensions.DependencyInjection.IServiceCollection},TestHarbor.ResourceCoordinator,System.Threading.CancellationToken,TestHarbor.TestSessionOptions)

summary: Runs a body and awaits cleanup, preserving both errors if both phases fail.

param resources: Resources retained for the complete body and cleanup.

param body: Async test work; await all child work before returning.

param configure: Optional service registrations.

param coordinator: Optional resource coordinator.

param cancellationToken: Cooperative cancellation passed to the body.

param options: Cleanup policy and diagnostic identity.

M:TestHarbor.TestSession.QuarantineResources(System.String)

summary: Marks the held resource set as requiring recovery, without releasing ownership.

param reason: Explanation recorded in resource snapshots.

M:TestHarbor.TestSession.DisposeAsync

summary: Stops extensions, disposes services, and then releases ownership.

remarks: Concurrent callers join the same cleanup task and observe the same errors.

TestHarbor.NUnit

T:TestHarbor.NUnit.HarborFixture

summary: Adds a TestHarbor session around each NUnit test using public lifecycle hooks only.

remarks: Keep InstancePerTestCase lifecycle. Do not hide the lifecycle methods. Constructors and OneTimeSetUp are outside resource ownership. Resolve services in SetUp or tests.

P:TestHarbor.NUnit.HarborFixture.Services

summary: Gets the current test's services, available through derived TearDown.

P:TestHarbor.NUnit.HarborFixture.Resources

summary: Declares all resources this test will need; may inspect public NUnit TestContext.

M:TestHarbor.NUnit.HarborFixture.ConfigureServices(Microsoft.Extensions.DependencyInjection.IServiceCollection)

summary: Registers this test's services; singleton registrations are session-local.

param services: Registration collection owned by this test session.

M:TestHarbor.NUnit.HarborFixture.OpenHarborSessionAsync

summary: Acquires the session before derived setup methods run.

M:TestHarbor.NUnit.HarborFixture.CloseHarborSessionAsync
